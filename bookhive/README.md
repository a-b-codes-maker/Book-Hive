# BookHive - Online Bookstore

A modern, responsive online bookstore shocasing indian authors and Bestsellers. Specially for Students and Casual readers.

## Features 

- Browse and search books by category
- Detailed Book pages with description
- Shopping carts with quantity controls
- User signup and login pages
- Fully responsive design(mobile,tablet,desktop)

## Buit with

- **HTML5** - Semantic markup
- **CSS** - Custom styling, Flexbox, grid, Animations
